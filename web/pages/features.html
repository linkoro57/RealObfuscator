Native transformations

Rename local bindings, encode string literals, transform supported integer values and redirect property access. Native mode adds control-flow dispatch without full virtualization.

The AST frontend handles supported Luau constructs, including type declarations, string interpolation and compound assignments. Invalid syntax returns an error before replacing your output.
