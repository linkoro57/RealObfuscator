FREQUENTLY ASKED QUESTIONS

Good questions.
Clear answers.

Compatibility, privacy and getting the most out of the engine.

Is RealObfuscator free? Do I need an account?

The browser tool is free to use and the project is open source under GPL-3.0-only. There is no account, subscription or payment step.

Is my source code uploaded anywhere?

No. The obfuscator and detector run locally in Web Workers through WebAssembly. Your source is not uploaded, stored in browser storage or executed. The site only saves your selected color theme. External GitHub links open GitHub when you choose them.

Does it support Roblox and Luau?

The target runtime is Luau / Roblox, including supported modern syntax such as types, interpolation and compound assignments. Test the generated script in your actual environment. See compatibility and limits for introspection and fallback behavior.

Which preset should I choose?

Start with Lightweight, then inspect size and behavior. Native adds structural changes; VM profiles add virtualization with higher costs. Compatible helps with native fallbacks, while Hardened enforces strict coverage. Compare the presets.

Why is my output much larger or slower?

Generated VMs, decoding helpers and additional transformations add code and execution work. Choose a lighter preset or adjust advanced settings. Measure performance on your target devices before releasing.

Can obfuscation make my code impossible to reverse engineer?

No. It increases analysis effort but cannot guarantee secrecy or prevent a dedicated analyst from reconstructing behavior. Keep valuable secrets and authoritative logic server-side.

What is a seed, and should I set one?

A seed makes output reproducible for the same input and settings. It is useful for debugging. Leave it empty when you want new randomized output, and avoid fixed development seeds for diversified releases.

What do native fallback warnings mean?

Some code cannot be compiled to the selected VM backend and remains native to preserve behavior. The report identifies these fallbacks. Strict coverage can return an error instead. Compatible provides partial virtualization with protected native literals.

Can I use an API or automate my builds?

There is no hosted HTTP API. Use the command-line tool for local automation, or integrate the Rust library. The CLI quick start explains the basic commands.

What files and sizes are supported?

The obfuscator accepts Lua/Luau source files up to 1 MiB. The detector accepts UTF-8 source up to 8 MiB. Use the CLI for larger scripts or jobs that exceed browser memory or the 120-second time limit.

Does a matching watermark prove who made a script?

No. The marker is public and may be forged, copied or removed. A match is evidence about the marker and normalized script content, not verified authorship. Open the identification tool.

Where can I report a bug?

Use the support page to prepare a GitHub issue with your preset, steps, error message and a minimal reproduction. Review any code before sharing it publicly.
