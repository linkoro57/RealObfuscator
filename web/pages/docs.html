GETTING STARTED

Your first obfuscation

  1. Open the workspace. Go to the obfuscator. A small Luau example is ready to try.
  2. Add your source. Paste your code or load a .lua or .luau file up to 1 MiB.
  3. Choose a preset. Start with Lightweight. Use advanced settings when you need specific transformations.
  4. Generate and inspect. Select Obfuscate. Review warnings and statistics, then copy or download your output.
  5. Test in your target runtime. Verify behavior and performance in your Roblox project or Luau environment before releasing.

Choose your starting point

Lightweight keeps overhead low. Rename focuses on binding names. Native adds dispatch transformations. Virtual machine compiles supported regions to bytecode. Compatible allows native fallbacks while binding their remaining literals. Hardened requires strict VM coverage.

Changing presets resets advanced settings. Compare all six presets before choosing a more expensive profile.

Make the output yours

Reproducible output

Leave the seed blank for a fresh randomized result. Set a decimal seed to reproduce output for the same source and configuration. The browser preserves the complete unsigned 64-bit seed.

Pretty output

Enable Pretty output for readable formatting. It does not undo the transformations; it makes inspecting generated code easier.

Advanced controls

Adjust naming, string decoding, VM behavior and coverage settings. Incompatible combinations return an error. Use Reset to preset to undo overrides.

Optimize code

Optimization is optional. Enable it in advanced settings to simplify supported expressions and remove provably unreachable branches before other transformations. Review the report and test the result.

Read the report

The Report panel shows source size, output size, size ratio, processing time and transformation counts. Expand All statistics for the full data, or download the JSON report.

Native fallback warnings mean some regions retain native execution. They are compatibility information, not proof that your script is fully virtualized. Strict coverage settings can reject these regions instead.

Use the command line

For larger scripts and automated local builds, use the Rust CLI. Install from a checkout with the Rust toolchain:

cargo install --path . --locked

Generate output with a specific mode and inspect statistics:

realobfuscator script.luau --mode native --stats

Use an explicit seed for reproducible development builds:

realobfuscator script.luau --mode vm --seed 42 --stats

Run realobfuscator --help-all for all options. The website has no hosted obfuscation API; use the CLI or Rust library for integration.

Identify a script

The identification tool accepts pasted code or a UTF-8 file up to 8 MiB. It checks for an embedded watermark and a visible attribution header without executing the script.

  • Matching watermark: a marker matches normalized script content.
  • Modified watermark: a marker exists but its recorded content does not match.
  • Header only: only the visible RealObfuscator attribution was found.
  • Not recognized: there is no recognized evidence; older or rewritten output may still be unrecognized.

Public markers can be forged or removed and cannot authenticate origin or authorship.

Compatibility and limits

The target runtime is Luau / Roblox. Not every Lua runtime or language construct is supported. Environment and stack introspection can require native fallbacks, and generated frames or local names may differ.

More VM layers, decoys and decoding work can increase output size, memory use and runtime cost. Browser jobs stop after 120 seconds. Use the CLI for scripts that exceed browser resources.

Obfuscation does not provide client-side secret storage. Keys, decoding logic and VM handlers are available to the client. Review the published extraction audit for concrete limits.
