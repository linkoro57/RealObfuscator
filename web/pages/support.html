First, try these.

The engine does not load

Reload the page, use a browser with JavaScript and WebAssembly enabled, and check that an extension is not blocking local scripts or Workers. If running a checkout, use an HTTP preview rather than opening an HTML file directly.

My script returns an error

Confirm that it parses as Luau, reset advanced settings, and try Lightweight. For VM coverage errors, inspect native fallback warnings or try Compatible. Keep a minimal example that reproduces the problem.

Output behaves differently

Test the original and output in the same target runtime. Try a lighter preset and review warnings about introspection or unsupported constructs. Include both expected and actual behavior in a report.

A job is too slow or too large

Cancel the job and use a lighter preset. Large scripts, deeply nested syntax and intensive VM options can exceed browser resources. The CLI is a better fit for larger jobs.
