How the website handles data, and where to find the project’s license.

Your scripts stay on your device

The obfuscator and identification tool process code in your browser. Source and generated scripts are not uploaded, executed or saved to browser storage. Reloading or leaving the tool discards the current workspace.

Downloads are created locally when you request them. Share your source, output and reports only when you choose to.

Theme preference

The site saves your selected color theme in local storage under realobfuscator-theme. The System setting follows your device preference. This value contains no source code or script data.

If browser storage is unavailable, you can still change the theme for the current page.

External services

The website uses no third-party analytics, hosted obfuscation service or external font CDN. Visiting a site makes normal HTTP requests for its pages and assets; your hosting provider may handle request logs.

Links to GitHub open an external service subject to its own policies. The support helper prepares an issue URL locally; you decide whether to open it and submit the report.

Read the attribution notices for the distinction between requests about output attribution and obligations when redistributing covered material.

Attribution markers

Generated output includes visible attribution and an embedded public marker. Please preserve the visible RealObfuscator attribution when sharing generated scripts. Markers can be removed or forged; they do not prove authorship or authenticity.

Scope and limitations

Obfuscation raises the effort required for analysis, but cannot guarantee confidentiality or resistance to deobfuscation. Test generated scripts in their target runtime and review the documented limits.
