# Local performance probe

Measured on 2026-11-13 with the release build of RealObfuscator 2.2.0 and the official Luau 0.741 Windows interpreter. This is a small local probe, not a security evaluation, a Roblox frame-time benchmark, or a comparison with Luraph.

The source is [examples/workload.luau](../examples/workload.luau). It runs a numeric loop of 100 iterations five times, verifies its work by printing `429250`, and prints elapsed `os.clock()` time. Results below are the median of five fresh interpreter processes per variant, with seed 42 for generated files. Timing starts inside the script after generated helper/prototype initialization; startup, parsing, compilation and initial payload decoding are excluded. Small native timings are particularly sensitive to timer resolution and machine load.

| Variant | Generated bytes | Median measured execution |
| --- | ---: | ---: |
| Original | 216 | 0.0217 ms |
| `--mode native` | 2,030 | 0.0326 ms |
| `--mode vm --vm-hardening basic --vm-cached --string-cache` | 25,391 | 1.0392 ms |
| `--mode vm --vm-hardening max --vm-rolling` | 33,820 | 51.5890 ms |

The maximal incremental decoder has substantial overhead on this hot loop. It intentionally trades speed and size for a smaller persistent decoded-data footprint and more diversified dispatch. It is not a suitable default for latency-sensitive code without workload testing. Cached VM mode materially reduces decoding costs while retaining decoded records; native/lightweight profiles avoid the register interpreter. These results do not imply any particular reverse-engineering time.

## Reproduce

```sh
cargo build --release
realobfuscator examples/workload.luau --mode native --seed 42 -o workload.native.luau
realobfuscator examples/workload.luau --mode vm --vm-hardening basic --vm-cached --string-cache --seed 42 -o workload.cached.luau
realobfuscator examples/workload.luau --mode vm --vm-hardening max --vm-rolling --seed 42 -o workload.max.luau

luau examples/workload.luau
luau workload.native.luau
luau workload.cached.luau
luau workload.max.luau
```

Repeat each invocation five times and take the median of the final printed value. Use the same interpreter, device, seed and source for comparisons. Profile actual game scripts in Roblox Studio before selecting a production configuration.
